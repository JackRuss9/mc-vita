# The Minish Cap for PS Vita – v1.1.2 (complete, tested 100%)

A native PS Vita build of [Project Picori](https://github.com/999sian/tmc) (the PC port of the [zeldaret/tmc](https://github.com/zeldaret/tmc) decompilation). No emulator: the game runs as native ARM code, in widescreen, at 55–60 fps.

**The whole game has now been played on a real Vita from start to finish at 100%**: every dungeon, every item and upgrade (all bomb bags and quivers, Remote Bombs, Light Arrows, Magic Boomerang…), all figurines and every Kinstone fusion. All the cheats and the randomizer were tested too.

**You need your own ROM** of *The Legend of Zelda: The Minish Cap* (USA), dumped from your own cartridge. This release contains **no game data**: no ROM, graphics, music or text. Everything from the game is extracted on your Vita from your ROM.

## Download
- `mc-vita-v1.1.2.vpk`: install with VitaShell. Updating from v1.0.0 keeps your saves and the extracted files in `ux0:data/tmc/`.

## Installing
1. Install `mc-vita-v1.1.2.vpk` with VitaShell.
2. Copy your ROM to `ux0:data/tmc/baserom.gba`.
3. Start the game. In the launcher, pick the region and language, then press **Play**.
4. **The first start takes a long time (it can be a couple of hours)** while the graphics and sound are extracted from the ROM, and the screen looks frozen. Leave it running. This happens only once; later starts take seconds. (Not needed again if you are updating from v1.0.0.)

## New since v1.0.0

### Faster
- **Frame drops fixed.** The port searched all of the game's loaded data one entry at a time on every graphics copy. Some places dropped to 14–20 fps because of it: the Minish path to Melari's Mines, Veil Falls with Biggoron, scenes with many sprites. Now it's a fast lookup, and those places run at full speed.
- The three render cores share the work dynamically, so the picture is ready sooner when the music or the system keeps one core busy (Mt Crenel in the storm, for example).
- **Text boxes** no longer drop to 40–48 fps with HD dialogue on: the HD text is built once when it changes instead of every frame.
- **File select** no longer stutters when the cursor passes over a randomizer save; the seed is loaded once, when you pick the slot.

### Fixed
- **Crash after loading a save state.** States made while a menu was open crashed when loaded. Save states are now made and loaded only during normal play, with a message otherwise. Auto-saves on area change wait until you're back in normal play.
- **Mt Crenel in the rain:** opening and closing the pause menu no longer scrambles the room.
- **Biggoron** (Veil Falls top) is drawn correctly in widescreen, from any direction.

### Better widescreen
The extra columns on the right of the 16:9 screen used to be black for some layers. They are now filled for:
- skies and static backgrounds (Veil Falls, Mt Crenel, Cloud Tops);
- fog, steam and light rays;
- the darkness of dark rooms (the cemetery);
- Mt Crenel's rain;
- the Minish path backgrounds.

### Randomizer works
- Its logic file is now included in the VPK.
- A new randomizer file opens with **Generate & Start** selected; press ✕ or **START**.
- The **Randomizer Mode** setting is remembered between sessions.

Works with the **USA** ROM:
1. On the file select screen, press **L** and tick **Enable Randomizer Mode**.
2. Pick an **empty** slot.
3. Press ✕ or START on **Generate & Start**.

### Cheats
- New: **Cucco minigame timer doesn't decrease**.

## Cheats (L+R → Cheats), saved between sessions
- Health, arrows, bombs and rupees don't decrease.
- Wallet always full.
- Bomb bag and quiver always full, to *your* current capacity.
- Mysterious Shells always 999.
- All regular Kinstones (99 each).
- Cucco minigame timer doesn't decrease.
- **Change name...**: rename Link at any time with the Vita keyboard. Save in-game to keep the name.

## Not tested yet
- **EU/PAL ROMs** (`baserom_eu.gba`) and the other languages.
- PS TV.

## Known issues
- The first start is very slow (see above).
- A few rooms with lighting effects, and Mt Crenel in the storm, run at about 45–55 fps.
- The xBRZ filters run at about 7 fps; use **nearest** (the default).
- Room transitions briefly show black side bars.
- A few special scenes may still be cut on the right in widescreen. Please report them with `log.txt`.
- The LiveArea icon and background are placeholders.

Found a bug? Please open an issue and attach `ux0:data/tmc/log.txt`. **Don't** attach or ask for ROMs or extracted files.
