# The Minish Cap for PS Vita – v1.1.3

A performance update for v1.1.2. Install over the old version with VitaShell: your saves and extracted files in `ux0:data/tmc/` are kept.

## Download
- `mc-vita-v1.1.3.vpk`: install with VitaShell.

## Fixed
- **Drops to 13 fps and multi-second freezes in dungeons** (seen in Deepwood Shrine). The game wrote to the memory card on its game and audio threads, and when the card was busy (writing an auto-save) both waited for it, sometimes for seconds.
  - **Auto-saves are now written in the background.** The small hitch at every door or room change is gone too.
  - **The audio thread no longer writes to the log**, so music doesn't stutter during saves.
- **Smaller, quieter `log.txt`.** The timing reports used while tuning the port are now off. The log still records saves, area changes and errors.

## For bug reports
To get the full timing log back, create an empty file named `debug_log` in `ux0:data/tmc/` (for example with VitaShell), then start the game. Attach `ux0:data/tmc/log.txt` to your issue.

## Tip
If text boxes feel slower with **HD dialogue (original glyphs)** turned on (Settings → Display), turn it off: the regular text boxes run at full speed.
