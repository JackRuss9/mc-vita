# The Minish Cap for PS Vita – v1.0.0 (first playable release)

A native PS Vita build of [Project Picori](https://github.com/999sian/tmc) (the PC port of the [zeldaret/tmc](https://github.com/zeldaret/tmc) decompilation). No emulator: the game runs as native ARM code, in widescreen, at 50–60 fps.

**You need your own ROM** of *The Legend of Zelda: The Minish Cap* (USA), dumped from your own cartridge. This release contains **no game data**: no ROM, graphics, music or text. Everything from the game is extracted on your Vita from your ROM.

## Download
- `mc-vita-v1.0.0.vpk`: install with VitaShell.

## Installing
1. Install `mc-vita-v1.0.0.vpk` with VitaShell.
2. Copy your ROM to `ux0:data/tmc/baserom.gba`.
3. Start the game. In the launcher, pick the region and language, then press **Play**.
4. **The first start takes a long time (it can be a couple of hours)** while the graphics and sound are extracted from the ROM, and the screen looks frozen. Leave it running. This happens only once; later starts take seconds.

## What's in it
- The whole game, native, widescreen in gameplay rooms, ~55–60 fps in most places.
- Picori's settings menu on **L+R**: graphics, audio, warp, randomizer and more.
- **Start skips the opening storybook.**
- **Cheats tab** (L+R → Cheats), saved between sessions:
  - health, arrows, bombs and rupees don't decrease;
  - wallet always full;
  - bomb bag and quiver always full, to *your* current capacity;
  - Mysterious Shells always 999;
  - all regular Kinstones (99 each).
- **Change name...**: rename Link at any time with the Vita keyboard. Save in-game to keep the name.
- Sound at 32 kHz GBA-accurate, without crackling. The renderer uses all 3 cores.

## Tested
USA ROM, English, on a real Vita. Tested from a new file through the first dungeon:
- sound and music;
- widescreen;
- the settings menu, warp and screen filters;
- every cheat;
- the name change.

## Not tested yet
- The rest of the game. It's the same code, so it should work.
- The **randomizer**. It's included; use **Roll new seed**, because you can't type a seed on the Vita.
- **EU/PAL ROMs** (`baserom_eu.gba`) and the other languages.
- PS TV.

## Known issues
- The first start is very slow (see above).
- Some dungeon rooms with lighting effects drop to ~40–48 fps. The file select screen runs at ~30 fps.
- The xBRZ filters run at ~7 fps; use **nearest** (the default).
- Room transitions briefly show black side bars.
- The LiveArea icon and background are placeholders.
